# Team 23 Project - miniMessenger

miniMessenger - A real time chat web application, deployed on Azure App Service with CI/CD via Github Actions and data persistence on MongoDB Atlas.

## Features

Features Implemented:
* Register Account
* Join Chat
* Send Message
* Received Message
* Authorize User
* LeaveChat
* Notification
* ForgotPassword
* Modify Message
* Show Past Chat History
* Show ALL Users (offline & online)  

> Each with its own Acceptance Criteria and Defense-in-Depth Validation (client-side, server-side, data layer)
