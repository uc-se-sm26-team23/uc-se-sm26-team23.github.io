About the Project

The Messenger application is a browser-based real-time platform for users to send and receive messages to each other, such as students receiving notifications from their teachers or friends chatting with each other for fun. It allows users to communciate via group and private channels, with additional features including sending and receiving notifications, seeing read receipts, managing various channels, and more.
